# Introduction

Backend for Frontend (BFF) is an architectural pattern where a dedicated backend layer is created specifically for a particular frontend application. Instead of having the frontend communicate directly with multiple backend services, the frontend communicates with a single backend tailored to its needs.

[Next.js](../../frontend/web/reactjs.md) is an example of a technology that implements the Backend for Frontend pattern. Although Next.js is primarily a React framework, its server-side capabilities allow developers to create server components, API endpoints, and server-side logic.
