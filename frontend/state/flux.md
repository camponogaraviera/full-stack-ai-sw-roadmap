# Introduction

Flux is an architectural design pattern for managing state and data flow in JavaScript applications. It was introduced by Facebook (Meta) for React-like apps to address issues with two-way data binding and unpredictable state updates.

As of 2023, [Flux has been archived](https://github.com/facebookarchive/flux) and superseded by [Redux](https://redux.js.org/).
