# Introduction

Flux is an architectural design pattern for managing client-side state and data flow in JavaScript applications. It was introduced by Facebook (Meta) for React-like applications to address issues with two-way data binding (a.k.a. bidirectional updates), found in architectural patterns such as [MVVM](../../architectural_patterns/mvvm.md), by replacing them with a strict unidirectional data flow.

As of 2023, [Flux has been archived](https://github.com/facebookarchive/flux) and superseded by [Redux](https://redux.js.org/).
