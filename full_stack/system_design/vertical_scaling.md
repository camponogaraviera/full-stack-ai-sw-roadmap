# About

In vertical scaling, scaling up is the practice of increasing the hardware's capacity (CPU, RAM, solid-state device) of an instance. 

Increasing resources does not eliminate a single point of failure, when everything is running on a single machine. There is a limit of how much a single machine can scale.
