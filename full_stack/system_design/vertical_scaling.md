# Introduction

In vertical scaling, scaling up/down means adding/removing resources (CPU, RAM, storage) of a single node or hardware instance.

Cons: There is a limit to how much a single machine can scale. Increasing resources does not eliminate a single point of failure when everything is running on a single machine.
